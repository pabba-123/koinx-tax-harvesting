# KoinX Tax Loss Harvesting App

## 🚀 Overview
This is a React-based application that simulates tax-loss harvesting for crypto investments.

---

## 🛠️ Tech Stack
- React (Vite)
- JavaScript
- CSS

---

## ⚙️ Setup Instructions

1. Clone repo:
git clone https://github.com/pabba-123/koinx-tax-harvesting.git

2. Install dependencies:
npm install

3. Run:
npm run dev
